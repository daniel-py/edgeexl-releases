# EdgeExl Tablet — downloads

Installable builds of the EdgeExl tablet app for Android.

The AI tutor runs entirely on the device. The speech and language models are packed inside the app, which is why the download is large.

## Download

**[Get the latest build →](https://github.com/daniel-py/edgeexl-releases/releases/latest)**

Open the link on the tablet and tap the `.apk` file under **Assets**.

## Install

1. Download the APK on the tablet. Use Wi-Fi: the file is about 1.7 GB.
2. Open the downloaded file. If Android asks, allow **Install unknown apps** for your browser or file manager.
3. Open EdgeExl. On first launch it unpacks its AI models (about 1.6 GB). Keep the app open until that finishes.
4. Sign in once while online. After the first sync the app works offline.

Updating from an earlier build? Install the new APK over the old one. If Android refuses the update, uninstall the old build first; you will then need to sign in and sync again.

## Requirements

- Android 7.0 or newer, on a 64-bit device
- About 5 GB of free storage during installation (the downloaded file can be deleted afterwards)
